# Security policy

Report a vulnerability privately through GitHub's security advisory feature for
`capisoft-lib/PiBlindHub`. Do not publish an exploit that can energize outputs, bypass the
local timeout, expose credentials, or reach GPIO through a network-facing process before a
fix is available.

Security support follows the latest released version. This pre-release refactoring branch
has no claim of physical certification. Software cannot replace the electrical protections
listed in `docs/HARDWARE_SAFETY.md`.
